# 验收范围

- 本地私人迁移版：448专家条目、359团队成员、15类、16技能；全量文件引用与安装哈希检查通过。
- 实际CLI加载：软件开发、一人公司、A股研究3个场景读取了技能、目录及方法文件，进程退出0。
- 普通CLI真实团队：产品分析师与独立QA完成范围V1、缺口检查、范围V2与复评；主代理核对来源及评分算例，协作机制验收通过。没有实际开发打字软件。
- 公开版与私人版范围不同：公开版只有15个许可明确主角色定义，其余433条只含目录和原创基础工作流。公开版不声称448份原文已全部开源。
- 开源版测试检查安装、覆盖、引用、角色模板与源码发布边界；具体机器和第三方服务仍需使用者按实际环境验证。
- 发布前本机24项标准库单元测试通过，包含私人转换器的身份剔除、仅角色导入和路径重叠保护。远端GitHub Actions结果以仓库实际运行记录为准。

未验证每个专家的专业效果、任何模型权重、第三方账号或专有服务。本项目不会把模型名称、角色人格、收益指标或源码模板当作执行证据。
