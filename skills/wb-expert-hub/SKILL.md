# WorkBuddy 专家库 · Codex 版

根据用户需求自动选择相关专业角色与工作流；用户无需输入技能名称。用户点名专家时优先精确匹配。复杂软件、研究、内容与营销任务按实际需要分工，普通问答和简单修改直接处理，不强制组队。

1. 先读 [Codex 适配约定](references/codex-adaptation.md)。
2. 用 `scripts/find_expert.py` 搜索名称、ID或领域；或读取 [目录](references/catalog.json)。搜索示例：`python scripts/find_expert.py 软件开发`。脚本仅在本地读取目录，不联网。
3. 用户点名时精确匹配；模糊需求选最相关的1个专家或团队，跨领域再补充必要角色。读取搜索结果的 profile，按需加载 methodology 和该插件 file-index 中的配套参考。
4. 对比当前可用技能与工具，按适配约定执行。团队角色可依授权和当前环境并行，单人小任务直接做；不能虚构已创建团队或调用专有工具。
5. 交付具体结果、证据、分歧与限制。没有完整定义的条目只称目录参考。源参考列出的目标百分比和名人身份不构成效果保证或真实本人参与。

按行业浏览：[类别索引](references/categories.md)。源包未安装任何第三方可执行代码、工具服务或凭证。
